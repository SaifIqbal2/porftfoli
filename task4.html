a) Platform Choice & Rationale

I have created a simple e portfolio based on thin HTML and CSS and a bit of JavaScript and will be hosted on Vercel. This method is quick, it is free to use in individual projects and it is more appropriate to entirely client side websites. The platform by Vercel automatically manages the static assets (HTML/CSS/JS) and contains preview and production environment, as well as is connected to Git to update it easily [1]. Regarding the content part, I used semantic HTML instructions to enhance its accessibility and structure to make pages easier to navigate and to export to screenshots [2].

Deployment flow: local edits → Git push → Vercel deploys to a live URL.

How I will deploy to Vercel

  1. Create a GitHub repository and push this folder.
  2. On vercel.com, add a new project and import the repo.
  3. No build command is needed (pure static). Set the root to the repository root.
  4. Click Deploy to get a live URL; add a custom domain if desired [1].
